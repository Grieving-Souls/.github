### VEILCRYPT

**Invisible Security for Digital Images**

An experimental security project exploring cryptography and steganography for protecting information within digital images.

**Highlights**

- AES-256-GCM encryption
- Ed25519 signatures
- SHA-256 integrity verification
- LSB-based data embedding
- Steganalysis & detection

**Stack**

`Python` `Cryptography` `Steganography`
